# Rendus

Un dossier par vidéo : le **MP4** + le **prompt.md** qui a servi à la faire.

- `videos/` — vidéos complètes (Showreel, DatacenterOise)
- `kit/` — chaque petit motion design du kit, seul
- `scenes-datacenter/` — chaque scène de la vidéo data center, seule

Tout se régénère avec `npm run rendus` (ou `npm run rendus -- Kit-` pour une seule famille).
Les MP4 ne sont pas versionnés dans Git (trop lourds) ; les prompts d'origine sont dans `prompts/`.
